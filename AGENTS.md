# libresearch-mc

Библиотечный мод для **NeoForge 1.21.1**: стол исследований с карточной мини-игрой.
Играешь карты → получаешь проценты в дисциплинах → проценты превращаются в очки знаний →
очки обмениваются на предметы/разблокировки. Всё контентное — data-driven JSON, позже
управляется из KubeJS.

Механика вдохновлена столом исследований Thaumcraft 6, но реализуется **с нуля** по
описанию поведения. См. `notes/01-...`, `notes/02-...` (разбор механики) и
`notes/03-mvp-design.md` (наш дизайн).

## Зафиксированные решения (не переспрашивать)

1. **Награда**: после завершения теории у дисциплины появляется ячейка с предметом
   (количество = целые очки × `count_per_point`). Клик забирает, остаток санти-очков
   остаётся в запасе. Пока есть незабранные награды — новая теория на этом столе не
   стартует, в GUI баннер «Заберите награды для продолжения». Текстура ячейки не нужна.
2. **Видимость дисциплин**: дисциплина невидима, пока у игрока нет по ней очков. Появились
   очки — дисциплина видна навсегда. Видимость — только отображение, на выпадение карт не
   влияет. «Запретная» дисциплина (звезда Незера) — обычная дисциплина с теми же правилами.
3. **Чернила**: отдельный предмет-чернильница, 100 зарядов. Крафт: стеклянная бутылочка +
   чёрный краситель + перо. Перезарядка: чернильница + чёрный краситель на верстаке →
   полная. 1 заряд за розыгрыш карты, отдельные карты тратят больше.
4. **Стол**: два слота — чернильница и бумага. Добор руки платит 1 бумагу, розыгрыш —
   1 заряд чернильницы. Переброс руки бесплатный (только бумага).
5. **Очки**: санти-очки, 100 = 1 очко. Проценты дисциплин целые, 100% = 1 очко.
6. **Штраф 2/3**: механика есть в коде, но в MVP по умолчанию выключен
   (`full_value_slots` = число дисциплин), иначе пример заказчика не сходится.
7. **mod id / пакет**: `libresearch` / `com.minemaster.libresearch`.
8. **Типов столов может быть больше одного** (`notes/07-multi-table.md`): тип стола — это
   датапак-определение `libresearch/table_type/<id>.json` со своими дисциплинами и бонусными
   блоками. Для отладки зарегистрированы два стола: `libresearch:research_table`
   (5 слитков + звезда Незера) и `libresearch:debug_table` (5 красителей; бонусные блоки —
   камень, обсидиан, бедрок).
9. **Чернильница тоже data-driven**: `libresearch/inkwell/<id>.json` задаёт предмет, ёмкость,
   цвет и расход на розыгрыш.
10. **Бонусные блоки в GUI** показываются всегда, даже если блока рядом нет: недостающий —
    тусклый, присутствующий — обычный, выбранный — подсвеченный; тултип объясняет, что это
    за блок. Это требование к GUI итерации 3/4, данные уже в `TableType.BonusBlock`.

## Правила кода

- Java 21 (toolchain), NeoForge 21.1.x, официальный ModDevGradle.
- Пакет `com.minemaster.libresearch`, mod id `libresearch`.
- Чистое ядро (`core/`) не импортирует Minecraft: математика процентов, пул карт, правила
  розыгрыша. Всё MC-зависимое — в `content/`, `block/`, `menu/`, `network/`, `client/`.
- Данные — только через Codec + `SimpleJsonResourceReloadListener`-подобный релоадер,
  с понятными ошибками парсинга.
- Никаких `static`-синглтонов состояния: состояние — в BlockEntity/attachment.
- Случайность — через переданный `RandomSource`, чтобы ядро тестировалось.
- Идентификаторы и код — по-английски, комментарии и заметки — по-русски.
- Юнит-тесты для `core/` обязательны там, где есть математика (конвертация, пул, лимиты).

## Сборка

```bash
export JAVA_HOME=/usr/lib/jvm/java-21-openjdk      # Java 27 по умолчанию не подходит
./gradlew --offline build                          # сборка работает полностью офлайн
```

Запуск игры (`runClient`/`runServer`) требует артефакт `neoforge-21.1.228-moddev-config.json`,
которого нет в кэше. Он тянется только через Tor (проверено, HTTP-прокси отвечает 200):

```bash
./gradlew -Dhttps.proxyHost=127.0.0.1 -Dhttps.proxyPort=9060 \
          -Dhttp.proxyHost=127.0.0.1 -Dhttp.proxyPort=9060 runClient
```

После первого успешного запуска артефакт попадает в кэш и `--offline` снова работает.
Если офлайн-сборка упрётся в отсутствующий артефакт — сначала Tor-прокси
(HTTP `127.0.0.1:9060`, SOCKS5 `127.0.0.1:9050`), потом GitHub Actions
(сборка на раннере, jar артефактом). Подробности — `notes/04-tech-environment.md` §5.

Версии для dev: MC 1.21.1, NeoForge **21.1.228** (кэш Gradle), MDG 2.0.140,
Gradle **9.6.1** (wrapper; MDG 2.0.140 с ним совместим — проверено сборкой).
Целевой инстанс для теста: `/home/minemaster/.local/share/PrismLauncher/instances/dev`
(NeoForge 21.1.262, KubeJS 2101.7.2). Детали и обходные пути — `notes/04-tech-environment.md`.
