# Заметки проекта libresearch

Мод-библиотека «стол исследований»: карточная мини-игра, которая превращает вдохновение
и расходники в очки дисциплин, а очки — в предметы/разблокировки. Механика вдохновлена
столом исследований из Thaumcraft 6, но реализуется с нуля по описанию поведения
(clean-room), без копирования кода и ассетов.

## Индекс

| Файл | Что внутри |
|---|---|
| `01-research-core-loop.md` | Разбор ядра мини-игры: ресурсы, вдохновение, добор, рука, учёт процентов, завершение теории |
| `02-research-cards-and-bonuses.md` | Каталог карт, дисциплины, бонусные блоки, порядок формирования раздачи, требования к предметам |
| `03-mvp-design.md` | Наш дизайн MVP: что делаем в этой итерации, схема данных, GUI, API расширения |
| `04-tech-environment.md` | Окружение: версии, кэш Gradle, сеть, инструменты, риски сборки |
| `05-open-questions.md` | Открытые вопросы к заказчику (нужны ответы перед кодом) |
| `06-cleanroom-log.md` | Журнал чистоты: что читалось, кем, что запрещено переносить |
| `07-multi-table.md` | Мульти-столы, подсветка бонусных блоков, data-driven чернильница |
| `08-dev-process.md` | Процесс работы: цикл итерации, лестница проверок, разбор багов, роли |
| `iter/` | Заметки по итерациям (создаются по ходу работы) |

## Правила ведения заметок

- Одна итерация = один файл в `iter/`, имя `NN-кратко.md`.
- В файле итерации: цель, принятые решения, затронутые файлы, как проверить, известные проблемы, что осталось.
- Числа баланса живут в JSON (`data/`), а не в коде и не в заметках. В заметках — только обоснование.
- Заметки пишутся по-русски, код и идентификаторы — по-английски.
