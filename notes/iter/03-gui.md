# Итерация 3 — GUI, меню, сеть

## Цель
Играбельный экран стола: `TheoryEngine` вызывается пакетами, состояние читается из BlockEntity.

## Что сделано
- `menu/ModMenus`, `menu/ResearchTableMenu` — 2 слота стола + инвентарь; ленивое разрешение BlockEntity на клиенте.
- `network/ModNetwork`, `network/TableActions` — `TableActionPayload` (START/TOGGLE_BONUS/DRAW/PLAY/FINISH/DISCARD/CLAIM/CLAIM_ALL), проверка меню/дистанции на сервере.
- `client/ResearchTableScreen` — один экран, три фазы: настройка бонусов → игра → награды.
- `theory/BonusScanner` — скан 9×9×3 + сущности ±5, подсветка «нет блока / есть / выбран».
- `client/CardText` — строки тултипов карт.
- Команды: `/libresearch open`, `/libresearch prepare [debug]` (ставить готовый стол и открывать меню).

## Найденные и исправленные баги (по отзыву заказчика)
1. **Весь интерфейс рисовался в левом верхнем углу**, а слоты — на своих местах: `renderBg` вызывается ДО сдвига позы на `leftPos/topPos`. Добавлен `pushPose/translate(leftPos, topPos)/popPose` вокруг всего рендера. Слоты, кнопки и тултипы совпали.
2. Кнопка «Начать теорию» не срабатывала по той же причине (хитбоксы съезжали вместе с рендером).
3. Клик по бонусному блоку, которого нет рядом, молча игнорировался — теперь шлётся на сервер, сервер отвечает причиной.
4. Нет подсказки, почему нельзя начать: добавлены строки «Бумага есть в инвентаре — положите её в правый слот» и то же для чернильницы.
5. `ClassCastException` в `SlotItemHandler.set` — ленивый handler должен реализовать `IItemHandlerModifiable`.
6. Награды/кнопки наезжали на инвентарь: высота панели 270, инвентарь 194/250, награды с y=46, «Забрать всё» в левой колонке.

## Автотест интерфейса
`client/UiTest` под `-Dlibresearch.uitest=true` (`-Puitest`): ставит стол, снимает скриншоты фаз в `run/screenshots/`, закрывает игру.

Запуск:
```bash
./gradlew --offline runClient -Puitest -PclientArgs="--quickPlaySingleplayer test"
```

**Ограничение:** в этом режиме меню открывается командой в том же тике, что и постановка блока.
Клиент может получить экран раньше обновления BlockEntity и показать старое состояние стола
(в тестовом мире накопились награды от прошлых прогонов). При обычном ПКМ по столу
BlockEntity уже есть на клиенте, поэтому боевой путь этим не затронут.

## Как проверить руками
1. `./gradlew --offline runClient`.
2. В мире: `/libresearch prepare` — стол с бумагой и полной чернильницей, меню откроется само.
   Либо скрафтить/поставить `libresearch:research_table` и положить бумагу + чернильницу в слоты.
3. Настройка: выбрать найденный бонус (верстак рядом) → «Начать теорию» → «Добор» → клик по карте.
4. `/libresearch theory inspiration 0` → «Завершить» → забрать награду кликом.

## Известные проблемы
- Тексты захардкожены по-русски, в lang только заголовок окна.
- Бонусная карта сгорает при доборе, а не при розыгрыше (расхождение с ответом С11).
- `/reload` не перестраивает открытые экраны.
- UiTest не годится для проверки «свежего» стола: гоняйте его в новом мире или очищайте награды.
